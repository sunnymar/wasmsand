# curl/libcurl TLS Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add HTTPS support to the Codepod curl/libcurl port: fetch-mode HTTPS first, then socket-mode HTTPS through mbedTLS.

**Architecture:** Keep one static curl artifact with `auto|fetch|socket` runtime selection. Fetch-mode HTTPS routes through `codepod.host_network_fetch` without invoking guest TLS or sockets; socket-mode HTTPS links mbedTLS into curl and proves a real TLS transfer. mbedTLS is added as a normal c-port dependency consumed by the curl Makefile.

**Tech Stack:** Deno tests, TypeScript sandbox/network bridge tests, curl 8.19.0 patches, mbedTLS 3.6.6 LTS, `cpcc`/`cpar`/`cpranlib`, static `libcurl.a`, static mbedTLS archives, Codepod `libcodepod.a`.

## Context

Spec: `docs/superpowers/specs/2026-05-01-curl-tls-design.md`.

Existing curl port:

- `packages/c-ports/curl/Makefile`
- `packages/c-ports/curl/patches/0001-codepod-network-mode.patch`
- `packages/c-ports/curl/patches/0002-codepod-fetch-transport.patch`
- `packages/c-ports/curl/canaries/libcurl-fetch-canary.c`
- `packages/c-ports/curl/canaries/libcurl-socket-canary.c`
- `packages/orchestrator/src/__tests__/curl-conformance.test.ts`

Current limitation: curl is configured with `--without-ssl`, so `https://`
URLs are rejected before the fetch transport can satisfy them unless the curl
patch claims HTTPS earlier.

mbedTLS pin: `mbedtls-3.6.6`.

Reason: the official Mbed TLS GitHub release notes state that 3.6.6 includes
security fixes and that Mbed TLS 3.6 is an LTS branch supported until at least
March 2027. Use the official `mbedtls-3.6.6` tag/submodule rather than GitHub
generated source archives when possible.

Update `0002-codepod-fetch-transport.patch` so the patched curl worktree has

```c
bool Curl_codepod_fetch_should_use(struct Curl_easy *data)
{
  enum curl_codepod_network mode = Curl_codepod_network_mode(data);
  if(mode == CURLCODEPOD_NETWORK_FETCH)
    return TRUE;

  if(mode == CURLCODEPOD_NETWORK_AUTO &&
     data->state.url &&
     strncasecompare(data->state.url, "https://", 8))
    return TRUE;

  return FALSE;
}
```

```make
REPO_ROOT := $(shell cd ../../.. && pwd)
FIXTURES := $(REPO_ROOT)/packages/orchestrator/src/platform/__tests__/fixtures
UPSTREAM := upstream
BUILD_DIR := build
WORK_DIR := $(BUILD_DIR)/work
PREFIX := $(BUILD_DIR)/prefix
CANARY_DIR := canaries

CPCC := $(REPO_ROOT)/target/release/cpcc
CPAR := $(REPO_ROOT)/target/release/cpar
CPRANLIB := $(REPO_ROOT)/target/release/cpranlib

.PHONY: all submodule-init worktree lib canaries copy-fixtures clean ensure-toolchain

all: lib canaries

submodule-init:
	@if [ ! -f $(UPSTREAM)/include/mbedtls/version.h ]; then \
		echo "==> Initializing mbedTLS submodule"; \
		cd $(REPO_ROOT) && git submodule update --init packages/c-ports/mbedtls/$(UPSTREAM); \
	fi

ensure-toolchain:
	cd $(REPO_ROOT) && cargo build --release -p cpcc-toolchain

$(WORK_DIR)/include/mbedtls/version.h: submodule-init
	mkdir -p $(WORK_DIR)
	rsync -a --delete --exclude='.git' $(UPSTREAM)/ $(WORK_DIR)/
	if [ -d patches ] && ls patches/*.patch >/dev/null 2>&1; then \
		for p in patches/*.patch; do \
			echo "==> Applying $$p"; \
			patch -d $(WORK_DIR) -p1 < $(abspath $$p) || exit 1; \
		done; \
	fi
	touch $@

lib: $(WORK_DIR)/include/mbedtls/version.h ensure-toolchain
	cd $(WORK_DIR) && \
		$(MAKE) lib \
			CC="$(CPCC)" \
			AR="$(CPAR)" \
			RANLIB="$(CPRANLIB)" \
			CFLAGS="-O2 -DMBEDTLS_PLATFORM_MEMORY" \
			LDFLAGS=""
	mkdir -p $(PREFIX)/include $(PREFIX)/lib
	rsync -a $(WORK_DIR)/include/ $(PREFIX)/include/
	cp $(WORK_DIR)/library/libmbedtls.a $(PREFIX)/lib/
	cp $(WORK_DIR)/library/libmbedx509.a $(PREFIX)/lib/
	cp $(WORK_DIR)/library/libmbedcrypto.a $(PREFIX)/lib/

$(BUILD_DIR)/mbedtls-version-canary.wasm: lib $(CANARY_DIR)/mbedtls-version-canary.c
	$(CPCC) \
		-I$(PREFIX)/include \
		-o $@ \
		$(CANARY_DIR)/mbedtls-version-canary.c \
		$(PREFIX)/lib/libmbedtls.a \
		$(PREFIX)/lib/libmbedx509.a \
		$(PREFIX)/lib/libmbedcrypto.a

canaries: $(BUILD_DIR)/mbedtls-version-canary.wasm

copy-fixtures: canaries
	cp $(BUILD_DIR)/mbedtls-version-canary.wasm $(FIXTURES)/mbedtls-version-canary.wasm

clean:
	rm -rf $(BUILD_DIR)
```

```ts
async function withLocalHttpsServer(
  handler: Parameters<typeof createServer>[1],
  fn: (url: string) => Promise<void>,
) {
  const cert = await Deno.readTextFile(resolve(import.meta.dirname!, 'fixtures/tls/server-cert.pem'));
  const key = await Deno.readTextFile(resolve(import.meta.dirname!, 'fixtures/tls/server-key.pem'));
  const server = createServer({ key, cert }, handler);
  await new Promise<void>((resolveListen) => server.listen(0, '127.0.0.1', resolveListen));
  const addr = server.address();
  if (!addr || typeof addr === 'string') throw new Error('expected TCP listener address');
  try {
    await fn(`https://127.0.0.1:${addr.port}/data`);
  } finally {
    await new Promise<void>((resolveClose, rejectClose) => {
      server.close((err) => err ? rejectClose(err) : resolveClose());
    });
  }
}
```
